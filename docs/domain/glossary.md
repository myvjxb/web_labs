# Глосарій термінів (Ubiquitous Language)

* **Product (Товар)** — конкретна одиниця музичного обладнання або аксесуар у каталозі магазину, що має ціну та залишок на складі.
* **Category (Категорія)** — логічна група товарів для фільтрації каталогу (гітари, педалі, струни тощо).
* **Catalog (Каталог)** — перелік усіх доступних та архівних товарів магазину.
* **User (Користувач)** — зареєстрована особа в системі, яка має роль покупця (`customer`) або адміністратора (`admin`).
* **Order (Замовлення)** — зафіксований намір користувача придбати один або кілька товарів.
* **OrderItem (Позиція замовлення)** — конкретний товар у складі замовлення із зафіксованою на момент покупки ціною та кількістю.
* **Stock (Залишок)** — кількість одиниць товару, доступна для замовлення на поточний момент.

## Уточнення термінів у різних піддоменах
* Термін **Item** має різне значення залежно від контексту:
  * У контексті **Catalog** це `Product` (товар із динамічною ціною та залишком на складі).
  * У контексті **Orders** це `OrderItem` (позиція в чеку з кількістю та ціною, зафіксованою на момент оформлення).
