# Roadmap проєкту Music Store

План розвитку системи на найближчі 4 тижні:

### Тиждень 3 — Моделювання домену (DDD)
* Виділення піддоменів (Каталог, Користувачі, Замовлення) та побудова контекстної карти.
* Створення глосарію термінів (Ubiquitous Language).
* Прототипування базових доменних класів/сутностей у коді (`Product`, `User`, `Order`).

### Тиждень 4 — Архітектура, OpenAPI та базовий CRUD
* Фіксація архітектурного стилю (модульний моноліт) через ADR.
* Опис контракту API у форматі `openapi.yaml` та перевірка у Swagger Editor.
* Реалізація повного CRUD (`POST`, `GET`, `PUT/PATCH`, `DELETE`) для товарів, додавання `GET /health` та юніт-тестів.

### Тиждень 5 — Стійкість та обробка помилок (Resilience)
* Реалізація ідемпотентності для `POST`-запитів (`Idempotency-Key`) та кореляції (`X-Request-Id`).
* Додавання rate-limiting (`429 Retry-After`) та єдиного формату помилок.
* Реалізація ретраїв з backoff, таймаутів (`AbortController`) та degraded mode на клієнті.

### Тиждень 6 — Контейнеризація (Docker)
* Написання `Dockerfile` та `.dockerignore` для бекенду та фронтенду.
* Налаштування `docker-compose.yml` для запуску зв'язки `frontend + api + db` однією командою.
