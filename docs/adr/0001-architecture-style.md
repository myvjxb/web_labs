# ADR 0001: Вибір архітектурного стилю (Модульний моноліт)

* **Статус:** Прийнято
* **Дата:** 2026-11-25

## Контекст
Команда складається з 2 розробників, проєкт (Music Store) знаходиться на початковому етапі розробки. Потрібно швидко реалізувати базовий CRUD без зайвих витрат на мережеву інфраструктуру, брокери повідомлень та розподілені транзакції.

## Рішення
Обрано стиль **модульний моноліт** із чітким розділенням на шари та доменні модулі в межах одного репозиторію та процесу Node.js.

## Альтернативи
* **Мікросервіси:** відхилено на поточному етапі через високу складність підтримки та деплою для команди з 2 людей.

## Наслідки
* **Плюси:** швидка розробка, простий запуск і тестування, відсутність мережевих затримок між модулями.
* **Мінуси:** спільний цикл релізу для всіх модулів.

## Умови перегляду
Повернемося до виділення окремих мікросервісів, якщо команда виросте (>5 розробників) або окремий модуль (наприклад, Orders) потребуватиме незалежного масштабування.
